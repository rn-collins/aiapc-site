# AI literacy for people whose work already has a standard of care.

AI is a Piece of Cake is a prelaunch AI-literacy programme for lawyers,
physicians, executives, and educators — professionals who cannot treat a
model's output as good enough and need to know where it fails.

**Live:** https://aiapc-site.vercel.app

The site is prelaunch. Checkout and personal-data inquiry collection are
closed, and enrollment is planned for November 2026, so the deployment
takes no payment and stores no enquirer details.
